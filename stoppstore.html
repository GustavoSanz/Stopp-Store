Sobre a Aplicação

A Stopp Store é a aplicação Android oficial concebida para disponibilizar, atualizar e gerir todas as criações de software e videojogos do ecossistema Stopp Studio.

Ao contrário de downloads convencionais em navegadores móveis, a aplicação Stopp Store estabelece ligação direta através de APIs de sistema com o gestor de pacotes do Android, simplificando transferências e verificando de forma autónoma a integridade e versões de cada ficheiro.

Funcionalidades Exclusivas

  • Instalação com 1 Toque: Descarrega e encaminha pacotes APK diretamente para o instalador do sistema sem múltiplos avisos do browser.
  • Deteção Automática de Aplicações: Identifica instantaneamente se aplicações como a Vera Watt já se encontram instaladas no teu telemóvel e disponibiliza botões para Abrir ou Desinstalar.
  • Notificações do Sistema: Alertas em tempo real na barra de estado quando surgirem atualizações para aplicações instaladas ou para a própria Stopp Store.
  • Atualizações em Segundo Plano: Verificação transparente de novas compilações com diálogo de atualização direta.
  • Design Glassmorphism Fluido: Interface otimizada a 120Hz com tema dark slate e baixo consumo de bateria.

Como Instalar no Telemóvel

  1. Clica no botão Instalar APK Nativo acima para descarregar o pacote de ~922 KB.
  2. Quando a transferência terminar, toca no ficheiro descarregado para iniciar a instalação.
  3. Se for a primeira vez que instalas um APK direto, permite a opção de instalar ficheiros desconhecidos quando o Android solicitar.
  4. Abre a Stopp Store e explora o catálogo completo com todas as funcionalidades nativas ativas!
